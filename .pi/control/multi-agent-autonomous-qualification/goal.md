# Goal: Multi-Agent Autonomous Workload Qualification

Status: DONE

## Authorized outcome
Establish with an end-to-end workload that the real canonical Controller policy and Agent catalog enable autonomous, context-grounded choices of optional profile and cwd across implementation, review, remediation, verification, and simple generic work.

## Scope
- Controller sees Goal/Plan/Task, `.pi/AGENTS.md` policy, catalog/inspect tools, and ordinary dispatch tools.
- Exercise implementation → review → remediation → verification as separate Tasks with durable `.pi` handoff.
- Record actual Controller-issued tool choices and resulting model/variant/cwd/session metadata.
- Preserve MA1/MA2/MA3 authority, assignment generation, and admission semantics.

## Exclusions
No Task-type routing in runtime, scheduler, ExecutionAttempt, shadow context authority, changes to authority/schema, or transcript-as-durable-memory.

## Completion
MA4 acceptance is complete with separated evidence: real configured-model specialist dispatch proves catalog/policy-grounded profile and contained cwd selection; deterministic integration proves dispatch parameter plumbing and the optional-agent/default-PiRoot-cwd generic runtime path. Real-model generic choice on any individual simple Task is non-blocking policy variance. MA4 focused/integrated and MA1–MA3 regression gates pass, and `npm run check` passes.
